# Repwise — Workout Coach

A workout tracker with a built-in coach: sets, reps, weights (kg), auto rest timer, 90+ gym and calisthenics exercises with form cues, training splits, progressive overload plans and a supplement guide.

Runs fully in the browser. Your workouts, history and profile are saved on your device (localStorage) — no account needed.

## Run it
- **Online:** enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root).
- **Locally:** open `index.html` in a browser.

## Install on your phone
Open the GitHub Pages link, then:
- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ menu → Install app / Add to Home screen

It then opens full-screen like a normal app and works offline.

## Files
- `index.html` — the whole app (HTML, CSS, JS)
- `manifest.json`, `sw.js`, `icon-*.png` — make it installable and work offline
